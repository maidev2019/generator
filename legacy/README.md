# Original project reference (2022)

These files are copies of the original `src/App.js`, `src/App.css`, `src/mapp4.js`, and `src/strId.js` from `generator-master.zip`. They are not imported into the new application.

The new app retains the original state-to-tax-office dataset in `src/data/taxOffices.js` and uses `avris-generator` for state-specific tax numbers; the other generators were refactored and tested.
